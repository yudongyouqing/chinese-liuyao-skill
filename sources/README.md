# 原始 OCR 资料

本目录保存本 Skill 使用的三份中文六爻 OCR 原始文本。它们是可回查的资料层，不是每次解读都要完整加载的默认上下文。

## 文件

- [`六爻理法进阶_OCR纯文本.txt`](六爻理法进阶_OCR纯文本.txt)：月建、日辰、日月作用、合的层次和应爻等理法主题。
- [`六爻象法进阶上_OCR纯文本.txt`](六爻象法进阶上_OCR纯文本.txt)：六神、综合取象和长生十二宫等象法主题。
- [`六爻象法进阶下_OCR纯文本.txt`](六爻象法进阶下_OCR纯文本.txt)：三刑、伏神、旬空、反吟、进退、隔山化爻、六害和八宫卦象等主题。

## 读取原则

1. 完整解读先读取 `../references/method-and-output.md` 和与问题直接相关的精炼参考。
2. 当精炼参考不足、术语存在歧义或用户要求查看原始依据时，再读取 `../references/source-index.md`，按主题和关键词选择对应文件。
3. 一次只检索与当前问题相关的文件和段落，不默认把三本全文全部放入上下文。
4. OCR 可能有错字、断句和专门术语识别错误。原文命中只能作为资料线索，必须与排盘字段、流派口径和完整证据链分开。
5. 引用原文时只保留当前判断所需的最小上下文，并标注文件、关键词和 OCR 不确定性。

## 快速检索

在仓库根目录运行：

```bash
rg -n -S "月建冲爻|日辰冲爻|日月作用|合的层次|应爻" sources/六爻理法进阶_OCR纯文本.txt
rg -n -S "六神|综合取象|长生十二宫" sources/六爻象法进阶上_OCR纯文本.txt
rg -n -S "三刑|伏神|旬空|反吟|进退|隔山化爻|六害|八宫卦象" sources/六爻象法进阶下_OCR纯文本.txt
```

检索命中后只读取相关上下文，不把一段 OCR 的单独表述当作唯一规则，也不以它替代盘面一致性校验、现实证据或专业判断。
