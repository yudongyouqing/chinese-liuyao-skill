# 动变、关系与应期

本文件用于补充动变、盘内关系和应期的核对框架。它是常见纳甲六爻语境下的条件性参考，不复制用户本地 OCR 原文，也不把单项关系当成现实事实或吉凶开关。

本文件引用本地资料时统一遵循：不复制整段 OCR 原文，只在必要时使用脱敏短摘要。

## 默认口径与前置

未指定流派时，采用常见纳甲六爻的默认口径：理法优先、象法辅助。先确定占问对象、时间范围、用神候选、世爻和应爻，再看月建、日辰、旺衰、生克和动变。空亡、暗动、进退、应期等有流派差异的内容，应注明采用的口径；同一卦内不要混用互相矛盾的规则。若字段不足，保留待确认状态，不为了套用关系而补猜盘面。

判断任何关系前，先问三个问题：它落在用神、世应、原神、忌神或其他与问题直接相关的爻上吗？它在月建、日辰和动变中有实际作用吗？它能解释用户所问的事件，还是只是盘面上的旁支现象？只有前两项和问题相关性都较清楚时，才把它写入主要依据。

## 平台标签核对边界

八宫、六合、六冲、游魂、归魂等可能是排盘软件生成的平台标签，命名、显示和推导口径可能随软件或流派不同。比如“艮宫”“六合”等标签可能只是排盘软件口径；软件、流派或来源未核明时，只标为平台字段，不作为主要依据。

- 先记录标签原值及来源（用户文字、清晰原图或具体排盘软件），再与本卦、变卦、动爻、世应和纳支逐项核对；不能只凭标签反推缺失字段。
- 标签与基础盘面字段不一致时，列出冲突并请求确认，不静默改写本卦、变卦、动爻或世应。基础字段已核对前，平台标签只能作为待确认的辅助信息。
- 六神同样要核对起首六神的来源和逐爻排列；来源不明或与盘面不一致时标为待确认，不把软件自动显示的六神当作独立证据。
- 只有软件/流派口径和盘面一致性都较清楚，且标签与问事相关时，才可在理法之后作为象法补充；不能用八宫或六合标签替代理法核对。

## 观察对象

| 对象 | 常见观察含义 | 使用边界 |
| --- | --- | --- |
| 动爻 | 本卦中明确发动的爻，提示变化、行动、条件转换或时间线索 | 动爻不自动代表好坏；先确认它代表谁、作用于谁，以及是否与用神或世应有关 |
| 变爻 | 动爻变化后形成的爻，提示变化方向、后续状态或新的作用关系 | 变爻要和本爻逐一核对，不能脱离本爻、月日和事件背景独立断事 |
| 静爻 | 没有明确发动标记的爻，常作当前结构、背景或相对稳定条件观察 | 静爻仍会受生克冲合，也不能简单等同于“没有作用” |
| 伏神 | 需要时从卦宫或相关取法中寻找、但没有直接显现在本卦的六亲或对象 | 先确认伏神取法、所在宫位和飞神；伏神出现不等于该事必然隐藏或发生 |
| 飞神 | 显现在本卦、位于伏神之上的对应爻，常与伏神的显隐、阻隔和承载关系一起观察 | 飞神与伏神的轻重和作用有流派差异，不能只见飞神就断压制或不能出现 |
| 暗动 | 表面静止、但因日辰冲等条件被视为具有即时变化迹象的爻 | 是否构成暗动、作用范围和有效期限常有差异；必须写明判定依据，不把日冲机械等同于暗动 |
| 回头生 / 回头克 | 动爻所化之爻回过来生扶或克制本爻，提示变化后的反作用方向 | 先核对五行和变爻，再看本爻是否为关键爻；回头生不等于必成，回头克也不等于必败 |
| 化进 / 化退 | 动爻向所采用规则中的进神或退神方向变化，提示势态推进、回落或阶段转折 | 进退的判定依赖地支、五行和流派口径；逐爻核实后才可作为时效或趋势线索 |

## 冲合刑害与空破

冲、合、刑、害、旬空、月破和日冲只是候选含义。应先确认它们作用于谁、发生在什么层次，再结合用神/世应和问事相关性排序。下表只列常见方向，不是单项吉凶表。

| 关系 | 常见候选含义 | 核对提示 |
| --- | --- | --- |
| 冲 | 变动、分离、碰撞、打破原状、催动或即时刺激 | 冲开、冲散、冲动和冲坏可能对应不同结果；看被冲爻的身份、强弱、动静及问题背景 |
| 合 | 联系、合作、牵连、汇聚、约束、拖延或缓冲 | 合住与合好不是一回事；要看合到谁、是否得时、是否妨碍用神行动 |
| 刑 | 反复摩擦、压力、纠结、自我限制或关系中的不顺 | 三刑等组合需逐项成立并核对参与爻，不能把任一刑关系直接写成伤害事实 |
| 害 | 隐性阻力、误会、暗中不顺、利益摩擦或不易明说的牵制 | 害不等于某人有恶意；只有与问题对象和作用链相关时才进入主要判断 |
| 旬空 | 暂未落实、不可得、隐而未显、等待条件成熟或表面有而暂不实 | 空有时是时机未到，有时是目标落空，也可能只是信息不全；要看出空、填实、冲合和全盘支持 |
| 月破 | 被月建所冲，阶段性失势、条件破损、难以维持或当月受阻的候选线索 | 月破不等于永久失败；还要看日辰、动变、出月以及它是否是关键爻 |
| 日冲 | 起卦当下的直接刺激、碰撞、启动、离散或事情的即时波动 | 日冲可能促成变化，也可能破坏稳定；日冲是否构成暗动、何时失效需按所选流派核对 |

这些关系不是“看见即下结论”的开关。相同的合可能表示联系、牵制或延迟，相同的冲也可能是推动或破坏；流派对空亡、月破、暗动和关系层次的权重并不完全一致。若理法链条与某个关系的象意冲突，保留冲突并降低置信度。

## 联动规则

反吟、进退、合局和多爻联动，只能在逐爻核对后使用。至少要确认每一条参与爻的本爻、变爻、地支、六亲、动静、与月日的关系以及它和用神/世应的联系；不能因为卦名像反复、两爻相合或出现多个动爻，就直接套用整组结论。

- **反吟**可作为反复、往返、状态翻转或不稳定的候选线索，但要先核对本卦与变卦、每一动爻的变化和事件是否确有来回结构。
- **进退**可提示推进、回落、阶段性变化或行动速度，但进神、退神的取法要统一，不能只按“进就是好、退就是坏”处理。
- **合局**需要核对参与地支、成局条件、旺衰、动静和用神相关性；局成与否、局对谁有利都不能由一个合字单独证明。
- **多爻联动**应沿着“谁发动、作用谁、变成什么、何时可能显现”的链条逐爻记录，删去与原问无关的旁枝，避免把复杂盘面讲成无证据的故事。

## 应期流程

应期先是事件是否会发生的问题，之后才是何时发生的问题。按下列顺序生成候选窗口：

1. **先判断事件基础。** 以用神、世应、月建日辰、生克制化和关键动爻核对事件是否有较清楚的支持、阻力或条件缺口；若事件本身尚不能判断，不先报日期。
2. **提取动态线索。** 在事件较有可能发生或条件明确时，观察动变、回头生克、伏神显现、进退以及与用神相关的合冲，记录它们指向的变化条件。
3. **生成时间候选。** 结合出空/填实、冲合触发、相关地支日月、月令转换和季节背景，列出日、旬、月或季节层级的候选窗口。不同层级的依据要分开写，不把最短窗口当成确定日期。
4. **回到现实条件。** 将候选窗口与用户给出的流程、约定、截止时间或可观察事件核对；若现实条件不支持，只保留传统层面的可能窗口并降低置信度。
5. **控制表达。** 证据不足时只说“可能在某条件具备后出现变化”或给出较宽时间段，不硬定日期；即使有日期线索，也要说明它只是传统解释的候选，不替代现实安排和核验。

## 简短应用框架

### 关系问题

先限定是问关系状态、对方近况、沟通、复合还是选择，不把不同问题混在一卦。再核对世爻、应爻和关系相关用神候选，观察双方的生克冲合、动变、空破及作用链；六神和卦名只在理法收敛后补充氛围或行为线索。输出应写成“较像存在联系/阻滞/反复的条件”，并指出仍需现实沟通或事实才能确认，不能断言对方必然有某种行为或关系。

### 财运 / 工作问题

财运可先看妻财、世爻和资金取得条件，再检查官鬼、父母、兄弟、子孙分别可能对应的职责、手续、分耗和产出；工作可先看官鬼、世爻、应爻及组织环境，再核对动变和阻力来源。把“资源是否存在”“能否落实”“何时可能推进”分开，不把见财、见官或某个冲合写成必赚、必升职或必然失业。投资、借贷和职业决定仍以现金流、合同、岗位信息和现实沟通为准。

## 边界

本参考只帮助整理传统术语和核对顺序。健康、人身安全、法律、投资等高风险问题必须转回症状、检查、合同、风险数据和合适的专业渠道；冲合刑害、空破和应期候选不能证明现实事实。
