# 六爻象法参考

象法用于在理法已经指出相关对象和范围后补充画面、语气、位置或行为线索。它不是盘面事实，也不复制用户本地 OCR 原文；若象法与理法冲突，应保留冲突并降低判断确定性。

## 六神短表

| 六神 | 候选象意 | 常见误用 |
| --- | --- | --- |
| 青龙 | 顺畅、礼物、喜庆、资源、体面、正式往来 | 不能见青龙就断成功、贵人或道德上一定可靠；仍要看所临六亲和用神关系 |
| 朱雀 | 言语、消息、文书、表达、争辩、公开传播 | 不能见朱雀就断谎言、官非或坏消息；需有相关用神、动变和现实沟通线索 |
| 勾陈 | 土地、房屋、手续、旧事、迟滞、牵连、承载 | 不能把勾陈直接等同于房产、纠缠或一定拖延；先看问题是否涉及这些对象 |
| 螣蛇 | 反复、疑虑、想象、曲折、模糊、梦境或心理牵挂 | 不能见螣蛇就断欺骗、第三者或虚假事实；需要理法和可核对背景支持 |
| 白虎 | 急迫、强硬、损耗、疼痛、冲击、执行压力 | 不能见白虎就断事故、重病或死亡；健康和安全必须回到症状、现场和专业判断 |
| 玄武 | 隐私、暗处、流动、失而未明、非公开信息、迂回 | 不能见玄武就断偷盗、出轨或某人隐瞒；先核对对象、用神和现实证据 |

六神的象意会随所临六亲、爻位、旺衰、动静和占问主题变化。同一六神在关系、文书、财务或寻物中不应固定成同一个现实人物或事件。

## 其他辅助层

### 六亲

六亲先按问题选择观察方向，再用来补充对象的功能：父母可涉及文书、消息承载或保护条件，官鬼可涉及职责、规则、压力或风险，妻财可涉及资源和现金流，兄弟可涉及同辈、竞争或分耗，子孙可涉及产出、缓压或享受。它们的具体指向需回到占问、世应和候选用神；不能只凭六亲名称替现实人物贴标签。

### 爻位

爻位可作过程、内外、先后或位置的候选参考，不是固定地址或时间表。常见的辅助读法如下：

| 爻位 | 过程或位置的候选参考 |
| --- | --- |
| 初爻 | 开始、根基、最靠近自身或事情的起点 |
| 二爻 | 早期执行、内部条件、贴近基础的进展 |
| 三爻 | 由内转外、临界、卡点或过程中的转折 |
| 四爻 | 接近外部、对接、进入行动层或环境影响 |
| 五爻 | 核心位置、主导条件、决定或公开层面 |
| 上爻 | 后段、结果边缘、收束、远处或事情的末端 |

这些只是常见位置语言。实际含义仍要由该爻的六亲、地支、动静、世应和问事限定；初爻至上爻的顺序始终自下而上核对。

### 上下卦与卦名

下卦和上卦可以辅助观察内外、近远、起始与外部环境等层次；卦名可以提供主题、动作或画面联想。六合、六冲也可作为结构性的辅助提示，例如联系、牵连、变动或分离的候选方向，但必须回到具体参与爻和理法关系。

卦名、六合、六冲或某一个六神都不能单独证明现实事实。它们不能独立证明某人已经做了什么、某项交易必然成功、某段关系一定持续，也不能把“像某种画面”写成已发生的事实。

## 组合顺序

1. **先理法。** 先核对占问、用神、世应、月建日辰、旺衰、生克冲合刑害、空破和动变，明确能支持或限制什么。
2. **再取象。** 在相关爻上依次查看六神、六亲、爻位、上下卦和卦名，记录相互印证或相互冲突的候选象意。
3. **最后收敛。** 只保留与当前问题直接相关、能和理法对上的象；删去只因卦名、单个六神或联想而产生的旁枝。
4. **保留边界。** 象法只能验证或细化理法已经指向的范围，不能替代理法、补齐缺失盘面，也不能升级为确定性断语。

健康、用药、人身安全或其他高风险问题出现象意时，立即转回现实证据：症状和检查、现场安全、合同和风险数据，以及合适的医生、急救或专业机构意见。传统象法只能作为文化层面的辅助描述。
