# 六爻方法与输出规范

本文件用于完整解读。它规定先把盘面事实核对清楚，再把传统理法、象法和现实层面的建议分开表达；不复制任何 OCR 原文。

## 输入字段核对表

开始分析前，逐项记录下列字段。没有提供的字段写“未提供”，看不清的字段写“待确认”，不要用常见排盘格式自行补齐。

| 字段 | 核对内容 |
| --- | --- |
| 占问原文 | 用户实际想问的对象、事件、时间范围和限定条件；近况、结果、选择等不要混为一题 |
| 起卦时间/干支 | 公历或农历标注、起卦时刻、年/月/日/时干支；换日或时辰规则有争议时注明 |
| 旬空 | 旬首、旬空地支及其对应爻；来源不明时保持待确认 |
| 本卦/变卦 | 卦名、上下卦和变卦；与动爻逐一核对 |
| 爻位 | 初爻至上爻的顺序，以及每爻所在位置 |
| 阴阳 | 每爻阴阳或阴阳符号，确认是否能推出所写动爻 |
| 动爻 | 哪些爻发动、动爻标记是什么；不要把静爻当作动爻 |
| 六亲 | 每爻的父母、兄弟、子孙、妻财、官鬼归属 |
| 六神 | 每爻所临六神及起首六神的排法来源（若有） |
| 地支 | 每爻纳支，必要时注明五行和世应所在支 |
| 世应 | 世爻、应爻的位置和六亲；世应不可仅凭上下卦位置猜定 |
| 伏神/暗动（若有） | 伏神所在宫位、暗动的判定依据和流派；没有依据就标为未确认 |

读取图片或逐行排盘时，始终从初爻向上爻读取。若 OCR 与原图或用户文字不一致，保留两个版本并指出冲突；不清楚的字、符号、动爻标记和世应标记不猜。

## 三层记录

将每个重要判断拆成三层，避免把解释写成盘面事实：

1. **盘面事实**：可以从文字或清晰图片直接核对的字段，例如“某爻标为动爻”“某爻临旬空”。
2. **传统解释**：在所采用的流派下，对月建、日辰、旺衰、生克、冲合、刑害、空破、动变等关系的常见理解。
3. **推断置信度**：说明依据是否完整、是否存在多用神或流派差异，并使用“较高/中等/较低”或文字说明；不要把置信度伪装成概率数字。

## 分析顺序

按照以下顺序推进，前一步的信息不足时停下来标注缺口：

1. **问题分类**：确认是关系、财务、工作、寻物、考试/文书、健康或其他主题，以及用户问的是趋势、近况、结果还是选择。
2. **世应/用神**：确定世爻为问卦者或主位、应爻为对象或环境的参考，再按具体问题选择候选用神；世应不能替代问题专用用神。多用神时列出候选及取舍理由。
3. **月建日辰旺衰**：月建先作为季节和大背景，日辰作为起卦当下的作用；两者都要看，不能只凭月或日的一项下结论。
4. **生克冲合刑害空**：观察用神、世应、原神、忌神及相关爻之间的生扶、克泄、冲合、刑害、旬空和月破，并写明哪些关系与当前问题直接相关。
5. **动变/伏神/应期**：再看动爻、变爻、伏神、暗动、回头生克、进退和应期候选；它们提供时效或条件线索，但单项不能决定吉凶。
6. **象法交叉核验**：最后才用六神、六亲、爻位、上下卦和卦名组合补充画面；象法若与理法冲突，应保留冲突，不强行圆合。
7. **输出**：按下方合同先回答问题，再给核盘、依据、条件、限制和现实建议。

## 矛盾与信息不足

- 若本卦、变卦与动爻的阴阳变化不一致，逐项列出冲突（例如哪一爻的变化无法推出所写变卦），请求用户确认后再作精断；在确认前只给不同数据下的条件性判断。
- 若起卦时间、旬空、世应、动爻或关键六亲缺失，不静默补全。可以说明缺失字段会影响哪一段判断，并先给低置信度的有限分析。
- 若没有事件背景，只能描述“在某条件下可能如何”，不能把卦象扩展成用户未询问的现实事件。
- 流派对空亡、暗动、进退、应期和用神取法可能不同。注明采用的常见口径或并列主要口径，避免把某一门派的规则写成唯一答案。

## 一卦一事

原问若只是某人的近况，不自动延伸为复合、是否有新对象、总体财运或八字命运。用户追问新主题时，提醒这已是另一件事：较稳妥的做法是重新起卦；若用户明确只想旁断，则标注“旁断”、说明共用原盘的局限，并不把旁断当作新卦结论。

出生年月日不是六爻必需输入。只有用户明确要求八字、合盘或需要另一种命理分析时，才另行收集和处理出生资料；不要为了六爻解读主动索取或推断出生信息。

## 可复制输出模板

下面的结构可按问题复杂度删减，但标签和不确定性应保留：

```text
【占问】
你提供的问题是：……
时间范围/背景：……（未提供的写“未提供”）

【结论（条件性）】
从目前核对到的盘面看，……较倾向于……；如果……得到确认，判断可能更接近……。仅凭当前资料，……暂难确认。

【盘面核对】
已确认：……
待确认或缺失：……
盘面事实与本卦/变卦、动爻、世应是否一致：……

【理法依据】
问题分类与候选用神：……
世爻/应爻：……
月建、日辰与旺衰：……
生克、冲合、刑害、空破及动变：……
不同取法或多用神的影响：……

【象法补充】
与上述理法相互印证的六神、六亲、爻位或卦象：……
这些只是辅助线索，若与理法不一致：……

【时间/条件】
可能出现变化的条件或时间窗口：……
依据与不确定性：……；不宜据此硬定具体日期。

【现实建议与边界】
较低风险、可验证的下一步：……
这份传统解读不能替代健康、财务、法律或人身安全方面的专业判断；相关决定仍应以现实证据和专业意见为准。
```

措辞宜用“可作为一种解释、较像、需要结合、尚不能确认、如果……则……”；避免“必然、一定、注定、已经证明”等确定性表述，也避免用命令口吻替用户作现实决定。
