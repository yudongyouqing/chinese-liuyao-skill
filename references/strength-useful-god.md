# 六亲、取用神与旺衰参考

本文件提供常见的取用和旺衰框架。它是可操作的传统文化参考，不是机械判定表；必须回到占问原文、完整盘面和所采用的流派。

## 六亲与世应的常用功能

六亲的含义随问题变化。下列是常见功能，不是把某个六亲永久绑定为某种现实人物：

| 六亲 | 常见观察方向 |
| --- | --- |
| 妻财 | 钱财、资产、物质资源、现金流；在部分关系问题中也可作伴侣候选，但必须由问者、关系和流派决定 |
| 官鬼 | 工作职责、组织规则、压力、约束和风险；在传统健康象意中也可能指病患线索，但不能据此诊断 |
| 父母 | 文书、合同、票据、消息、证明、房屋或承载/保护条件 |
| 兄弟 | 同行同辈、竞争、分担、分耗、借贷或资源分流 |
| 子孙 | 产出、享受、缓压、解决问题的空间；也可按问题指向子女、宠物或成果 |

世爻通常代表问卦者或主位，应爻通常代表所问对象、对方或外部环境。它们有助于定位关系和作用方向，但都不能替代问题专用用神。问感情时，不应只因性别就强行把某一六亲套给对象；先确认用户问的是自己、特定对象、关系状态还是婚恋结果，再结合关系背景和采用的取法。卦中同类爻多现时，应列出候选并说明取舍，而不是静默选一个。

## 按问题选择候选用神

| 问事 | 候选观察对象 | 取用提示与边界 |
| --- | --- | --- |
| 感情、关系 | 世爻、应爻，以及由问者和对象性别/关系背景决定的候选六亲 | 先明确谁在问、问谁、问关系的哪一面；不把妻财或官鬼固定成所有关系中的唯一对象。世应的互动是关系结构线索，用神仍需按具体问法确认 |
| 财运 | 妻财、世爻，必要时官鬼、父母、兄弟、子孙 | 财爻可观察收入、资产和现金流，但要结合钱从哪里来、何时到账、是否有责任或分耗；不能仅见财爻就说必赚 |
| 工作/事业 | 官鬼、世爻，应爻或组织环境 | 官鬼可观察岗位、责任、规则和压力；世爻看承受与行动位置；父母可涉及制度文书，兄弟可涉及竞争，子孙可涉及产出或缓压，均须由问题限定 |
| 寻物 | 所寻物品对应的六亲、世爻、应爻及方位/环境线索 | 财爻常可指一般物品或资源，但文件、证件、车辆、房屋等可能更接近父母；先按物品性质和失物背景取候选，不把单一爻位直接当成地点事实 |
| 考试/文书 | 父母、官鬼、世爻，应爻或评审/机构环境 | 父母可看题目、文书、证件和消息承载，官鬼可看规则、资格、录取或压力；具体是考试分数、申请材料还是审批结果，取法会不同 |
| 健康 | 世爻、官鬼及相关生扶制化线索 | 只作传统文化象意，不能诊断、预测病情或替代就医；疼痛、症状、用药和安全问题以医生、急救和现实检查为准 |

感情、财运等主题若同时涉及工作、合同、第三方或选择，应把主问题和附带问题分开；不要为了填满表格而增加用户没有问的用神。

## 用神、原神、忌神与仇神

- **用神**是当前问题的观察中心，先回答“要判断的对象或事件是什么”，再从六亲、世应和背景中取候选。用神不等于结论。
- **原神**通常是能生扶用神、提供资源或支持条件的爻。它有力、得时、发动与否只是线索，还要看是否被冲克、空破或被关系链截断。
- **忌神**通常是直接克制或消耗用神的阻力。忌神出现不自动意味着失败，因为它也可能受制、无力、落空，或反映用户真正要面对的条件。
- **仇神**常指不直接决定用神、却会损伤原神或改变生克链的间接因素。它更适合描述阻滞来源和条件变化，不适合单独定吉凶。

这些名称是分析关系的语言，不是把盘面套入“看到某神就必然发生某事”的公式。判断时把用神、原神、忌神、仇神与世应、月建、日辰、动变一起看，并说明哪些环节仍缺资料。

## 旺衰与作用关系

1. **月建**首先是季节背景和整体气势，说明某五行在当月的得令、受制或阶段性状态；它不是脱离全盘的最终结论。
2. **日辰**更贴近起卦时点的当下作用，可对爻产生生扶、克制、冲合等影响；日辰也不能孤立取代月建和盘内关系。
3. 用神强弱至少结合生扶、克泄、冲合、空破、变爻和世应。相同的“旺”或“弱”在不同问事中可能代表资源、压力、显现程度或变化速度不同。
4. 动爻通常带来更强的时效或事件变化线索，但动爻不自动等于吉，也不自动等于坏；要看它是谁、动向何方、与用神和世应怎样作用。
5. 空亡、月破、日冲、合、刑、害的常见含义只是候选解释。例如空亡可能涉及未落实、暂隐、落空或时机未到，合可能涉及牵连、约束、汇聚或缓冲；实际含义须结合全盘、问题和流派核验。

遇到“某爻很旺”或“某爻旬空”时，应继续回答：它是否为用神或关键关系？是否得月建、日辰或动变支持？是否同时受冲、克、合、破？它在问题中代表的对象是否明确？若不能回答，不应把单项状态升级为现实断言。

## 财运专题

财运不能只看妻财一项。可以按具体问题同时检查：

- 妻财爻：收入、资产、现金流或可取得的物质资源；还要区分“有资产”与“现金能否按时到账”。
- 官鬼：工作责任、职位约束、债务压力、风控或产生收入的责任来源；它不等于财富本身。
- 父母：合同、票据、账户记录、审批、信息承载，也可能代表手续成本和支出凭证。
- 兄弟：竞争、分耗、合伙分配、借贷、人情支出或资源被分流。
- 子孙：产出、变现能力、消费享受和缓解压力的方式；在某些财务问题中可作生财或减压线索，但要结合财爻和世爻。

“正财”“偏财”和风险投资必须先具体化：是固定工资、经营收入、一次性交易、投机机会还是长期资产配置。不同问题的可观察对象和风险不同，不能用一个财爻结论覆盖所有场景。投资、借贷、保险、税务和重大支出应以合同、现金流、风险承受能力及合格专业意见为准。

## 现实边界

空亡、月破、日冲、合、刑、害以及六亲旺衰都只是传统解释中的候选线索，流派之间可能有不同权重。高风险的健康、财务、法律和人身安全决定必须以现实数据、专业人员和必要的紧急服务为准；六爻不能证明某人已经做了什么、某病必然如何、某项投资必然获利或某个法律结果必然发生。
